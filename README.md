# Site — Igor Flores | Perito Grafotécnico

Site institucional estático, sem banco de dados e sem hospedagem paga.

## Arquivos
- `index.html` — estrutura e conteúdo
- `styles.css` — identidade visual e responsividade
- `script.js` — menu mobile, ano automático e formulário via e-mail

## Publicação gratuita
O projeto pode ser publicado gratuitamente em GitHub Pages ou Cloudflare Pages e conectado a um domínio próprio.

## Importante antes de publicar
O site usa o e-mail `igor.flores81@gmail.com`, já informado no projeto. O telefone/WhatsApp não foi inserido como número porque ele não foi confirmado nesta etapa; assim evitamos publicar um contato incorreto.

O formulário não depende de serviço pago: ao enviar, ele abre o aplicativo de e-mail do visitante com a mensagem já preenchida.

## Observação
A fonte do Google Fonts é carregada externamente. Se você quiser que o site funcione sem nenhuma dependência externa, podemos trocar por fontes locais do sistema na próxima versão.
